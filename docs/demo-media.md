# Demo screenshots and video

No original board-screen capture or video has been cleared into this archive. To avoid presenting a fabricated capture as evidence, `assets/demo-result.svg` is explicitly a result card rendered from archived logs and `assets/demo-input.jpg` is the fixed benchmark input used by the historical throughput run.

When publication approval is available, add media only with:

1. a visible KV260/PYNQ execution context;
2. the exact command, source tag, overlay hash, and asset manifest identifier in a caption or adjacent `media-metadata.md`;
3. confirmation that all shown prompts, images, terminal information, and voices are publishable;
4. a direct link from the README, with a clear distinction between a live demo and an archived result.

Suggested paths are `assets/demo-screenshot.png` and `assets/demo-video.mp4`. The `.gitignore` excludes video by default so that large media can be attached through a release or external hosting after review.
